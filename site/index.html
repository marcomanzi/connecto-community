      What it does
      
A workspace built for more than one agent.

      
The CLIs you already use, unchanged, running in real terminals. Connecto adds what is missing between them: a way to talk, a way to share skills, and a way to stop everything at once.

    


    

      

        

        
Agents that use each other

        
Every terminal gets a connecto command. An agent can list the other terminals, read them, open a new one, ask a question and get just the answer back, delivered into its context when the other agent finishes.

        
$ connecto add codex --name "review the diff"
$ connecto send codex-4 --ask <<'EOF'
Review the migration in db/2031_orders.sql. Anything unsafe?
EOF
request r12 · the reply arrives when codex-4 finishes

One brake for everything

        
⌘ . pauses every agent action: sends, keys, new terminals, automations, remote input. An agent cannot lift it. Every action is written to a hash-chained audit log with secrets redacted.

        Automations
        
Stop babysitting permission prompts.

        
An automation is a small rule: when a terminal shows this, press these keys. You describe it in plain words, or paste a screenshot, and an agent writes the rule with you.

        
    
          
  • A local text trigger runs first, so the classifier is called only when it could matter.
    • 
          
  • A classifier model (Jev, with your own key) decides whether the screen really is the one you meant.
    • 
          
  • Below your confidence threshold, Connecto asks you instead of typing.
    • 
          
  • Rate limits, a per-terminal cutoff, and Pause all apply. Every call is in the history.
    •

        Skills & Plugins packages
        
Your team's skills, in every project.

        
A package is a folder of skills, subagents, commands, hooks and plugin settings for Claude Code and Codex. Pick a default, add more per project, and Connecto copies the right files in.

        
    
          
  • The built-in package ships team workflows where each tool reviews the other's work.
    • 
          
  • Packages can extend one another, so a team base plus a project layer just works.
    • 
          
  • Updates remove what a package dropped and leave files you edited alone.
    • 
          
  • Settings are merged, never overwritten: keys you set stay yours.
    •

        Isolated and system terminals
        
Keep a project separate. Or don't.

        
For each project, and for each tool, you choose where the CLI keeps its login, history and configuration.

        
    
          
  • System default (the default) uses your own ~/.claude or ~/.codex, exactly like a terminal you opened yourself.
    • 
          
  • Isolated (advanced) gives the project a private profile. A client project never sees your personal account, plugins or history.
    • 
          
  • Separately, choose how agents launch: skip permission checks, let a model review each action, or ask before acting.
    • 
        

        Isolated and system terminals →
      

      

        

          

            
System default default

            
Your everyday login, settings and plugins. No second sign-in.

            ~/.claude · ~/.codex
          

          

            
Isolated advanced

            
Own login, own history, own settings. Nothing shared with other projects.

            …/connecto/projects/<id>/profiles/claude
          

        

      

    


    

      

        Remote sessions
        
The agents on your other Mac, in this window.

        
Leave the heavy work running on a desktop and check in from a laptop. A paired host appears in the sidebar like a project, with its terminals live.

        
    
          
  • Pair with a six-digit code that lasts two minutes and works once.
    • 
          
  • Direct encrypted connection, with a relay only when a direct path cannot be found.
    • 
          
  • Watch, type, use the mouse, add, rename, restart and close terminals.
    • 
          
  • Off until you turn it on. Paired devices are listed and can be revoked.
    •

      Download
      
Get Connecto.

      
A native macOS appapp for macOS and Windows. No Connecto account: your agents use the logins you already have.

    

    

    
The Mac builds are signed and notarized by Apple. Open the disk image, drag Connecto to Applications, and open it. Step by step → Linux and Windows are not available yet.
Windows: the build is not signed yet, so Windows SmartScreen warns the first time you start it: click More info, then Run anyway. Windows steps → Linux is not available yet.

    
Needs macOS, or Windows 10 (1809) or later on x86_64, and Claude Code or Codex already installed. Installation guide →
