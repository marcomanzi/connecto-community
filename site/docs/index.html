Introduction

Connecto is a macOS app that runs coding agents in real terminals, side by side, and lets them work together.

Today it runs Claude Code, Codex, Pi and Antigravity CLI. Cursor CLI and opencode are next. Each agent runs as the CLI you already know, unchanged, in its own terminal. Connecto adds the parts that are missing when you run several of them at once:

  • A workspace. Every project is open at the same time, each with up to 16 terminals, in one sidebar that shows which agent is working and which one is waiting for you.
  • A way for agents to talk. Each terminal gets a connecto command, so an agent can open another terminal, ask it a question, and receive the answer when it is ready.
  • Automations. Rules that answer a prompt for you when a terminal shows a screen you described.
  • Agentic Works. A PostgreSQL job queue: a program inserts a row, an agent does the work, and validated JSON comes back.
  • Skills & Plugins packages. Skills, subagents, commands and plugin settings that Connecto installs into every project that uses them.
  • Isolated or system profiles. A project uses your own login and settings by default; an advanced option gives it a private login and settings for each tool.
  • Remote sessions. The terminals on another Mac, shown and driven from this one.
  • One brake. Pause stops every agent action at once, and an audit log records what agents did.

What Connecto is not

  • It is not a sandbox. Agents run as your user, with your files and your network. Read Pause, audit and redaction before giving an agent a task you would not give a colleague with your laptop.
  • It is not a model provider. You sign in to each tool with your own account, and usage counts against your own plan.
  • It does not replace the CLIs. It runs them. What you can do in Claude Code, Codex, Pi or Antigravity CLI, you can do here.

Source code and contributing

Connecto is free software under the GNU AGPL-3.0. The source is on GitHub: github.com/marcomanzi/connecto-community. You can read it, build it yourself (the README there says how) and send pull requests.

Found a bug, or something that does not work the way these pages say? Open an issue: github.com/marcomanzi/connecto-community/issues. Say what you did, what you expected and what happened, with your Connecto version (Connecto → About) and your macOS or Windows version.
