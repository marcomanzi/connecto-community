connecto-app

From the downloaded app it is /Applications/Connecto.app/Contents/MacOS/connecto-app; the connecto command inside agent terminals is provided by the app, not installed on your PATH.

CommandWhat it does
connecto-appStarts the app and restores your workspace.
connecto-app --project <folder>Starts the app and opens that folder as well.
connecto-app provisionFor scripts: copies your installed CLIs into Connecto's store (the app does this by itself at its first launch). Run it again to pick up a newer version of a tool.
connecto-app audit verify <file>Checks that an audit log has not been edited.

Where secrets are kept

The Jev key, this machine's device keys, the relay token and the keys of paired machines are kept in one file, secrets/secrets.json in the data folder. Only your account can read it: on a Mac the file is readable by you alone (mode 600, in a folder of mode 700), and on Windows it sits in your own %APPDATA%. It is replaced in one step on every change, so it is never left half written. This is how command-line tools such as gh, ssh and aws keep their credentials, and it means Connecto never asks for Keychain access.

To keep secrets in the system store instead, turn on Settings → Remote Access → Store secrets in the system keychain (on Windows: Store secrets in Windows Credential Manager). The change takes effect at the next start, which moves the secrets across. Turning it off again moves them back to the file.

Up to 0.1.7 the secrets were in the Keychain. The first start of 0.1.8 reads that Keychain item once, writes the file and deletes the item, so macOS asks one last time. If you refuse, Connecto starts with no secrets and does not ask again: this machine gets a new device identity, so paired machines have to be paired again, and the relay token and the Jev key have to be entered again.
